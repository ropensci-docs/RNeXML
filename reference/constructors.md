# Constructor for the respective class

Creates an instance of the class corresponding to the respective NeXML
element, and initializes its slots with the provided parameters, if any.

## Usage

``` r
nexml.tree(...)

nexml.trees(...)

nexml.node(...)

nexml.edge(...)

nexml.otu(...)

nexml.otus(...)

nexml.char(...)

nexml.characters(...)

nexml.format(...)

nexml.state(...)

nexml.uncertain_state(...)

nexml.states(...)

nexml.uncertain_states(...)

nexml.polymorphic_states(...)

nexml.member(...)

nexml.matrix(...)

nexml.row(...)

nexml.seq(...)

nexml.cell(...)
```

## Arguments

- ...:

  optionally, parameters passed on to
  [`new()`](https://rdrr.io/r/methods/new.html)

## Details

Usually, users won't need to invoke this directly.
